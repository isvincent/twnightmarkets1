# 🏮 台灣的夜市｜互動學習網

以「臺灣夜市文化」為主題的互動學習網站。網站介面可以切換**國語／台灣台語**，裡面有教師與學生學習指引、互動視覺化元件、進階延伸、練習、測驗、學習歷程紀錄。網站是 **RWD + PWA**，手機、平板、電腦都能用，也可以安裝到桌面離線使用。

> 這個網站只用 HTML、CSS、JavaScript 寫成，不必安裝或建置，上傳 GitHub Pages 就能使用。

### ⚙️ 顯示與操作設定（七大切換）

| # | 設定 | 選項 |
|---|---|---|
| 1 | 全螢幕 | 開啟／關閉 |
| 2 | 音效 | 開啟／關閉（音效用 Web Audio 即時合成，不需要音檔） |
| 3 | 裝置 | 自動／手機／平板／電腦（模擬不同裝置的版面寬度） |
| 4 | 版面 | 自動／直式（上方選單）／橫式（側邊選單） |
| 5 | 語言 | 國語／台語（全部介面和教材文字一起切換） |
| 6 | 字體 | 縮小／標準／放大（基本字級 19px） |
| 7 | 色系 | 跟隨系統／亮色／暗色 |

設定會存在瀏覽器（localStorage），下次打開時還是一樣。

## 🚀 上傳到 GitHub Pages

1. 登入 GitHub，按右上角 **＋ → New repository**，取一個名稱，例如 `taiwan-night-market`，設為 **Public**。
2. 進入新的 repository，按 **Add file → Upload files**，把本資料夾**裡面的所有檔案和資料夾**（`index.html`、`css/`、`js/`、`icons/` 等）拖進去，按 **Commit changes**。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 等 1～2 分鐘，網址會是：`https://你的帳號.github.io/taiwan-night-market/`

如果要用指令上傳：

```bash
git init
git add .
git commit -m "台灣的夜市 互動學習網"
git branch -M main
git remote add origin https://github.com/你的帳號/taiwan-night-market.git
git push -u origin main
```

### 📲 安裝成 App（PWA）
- **電腦 Chrome／Edge**：網址列右側會出現「安裝」圖示。
- **Android**：Chrome 選單 →「加到主畫面」。
- **iPhone／iPad**：Safari 分享 →「加入主畫面」。

打開過一次以後，沒有網路也能使用。

## 🛠️ 修改教材

全部教材都在 `js/data.js`。每段文字的格式是 `['國語', '台語']`：

```js
title: ['夜市是什麼？', '夜市仔是啥物？'],
```

- 新增測驗題：在 `QUIZ` 加一筆。`a` 是正確選項的索引（從 0 開始），作答時選項順序會自動打亂。
- 新增小吃：在 `FOODS` 加一筆（`zh` 國語名、`tw` 台語名、`tl` 台羅拼音、`p` 示意價格）。
- 修改檔案後，請把 `sw.js` 裡的 `CACHE = 'nightmkt-v1'` 改成 `v2`，已經安裝的使用者才會拿到新版本。

### 在自己的電腦預覽
因為有 Service Worker，建議用本機伺服器開啟：

```bash
python -m http.server 8000
```

然後打開 `http://localhost:8000`。直接雙擊 `index.html` 也能用，只是不會有離線功能。

## 📝 說明
- 台語文字採用教育部推薦用字，台羅拼音只供參考，建議請台語老師校對。
- 夜市營業日、小吃價格、經營模擬器數據都是**教學示意**，實際情況以各夜市公告為準。
- 學習紀錄只存在學生自己的瀏覽器，不會上傳到任何伺服器；需要繳交時，請在「學習歷程」下載檔案。
- 字型使用 Google Fonts（Huninn 粉圓、Noto Sans TC）；沒有網路時會改用系統字型。
